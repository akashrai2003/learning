# Extensions after the combined core

All original material remains available. These branches turn surveys or deferred implementations into deeper practice. Select **one** for the next 8–12 weeks, with roughly 12–14 technical hours/week. Some branches need more time or hardware; the durations below describe a first bounded project, not mastery.

| Branch | Original starting resources | First bounded project | Entry requirement |
|---|---|---|---|
| PyTorch training and fine-tuning | [P23 torchtune](originals/pytorch-systems-and-deployment-curriculum/modules/23-torchtune-recipes-and-finetuning.md), [P45 FSDP](originals/pytorch-systems-and-deployment-curriculum/modules/45-fsdp-and-sharded-training.md), [P48 checkpointing](originals/pytorch-systems-and-deployment-curriculum/modules/48-distributed-checkpointing-elasticity-and-reliability.md) | Reproduce one small recipe, change one condition and document quality, memory and resume behavior | Tiny training/evaluation gates pass; compatible resources for chosen recipe |
| Compiler/framework internals | [P32 AOTAutograd](originals/pytorch-systems-and-deployment-curriculum/modules/32-aotautograd-functionalization-and-autograd-graphs.md), [P37 dispatcher](originals/pytorch-systems-and-deployment-curriculum/modules/37-dispatcher-aten-and-autograd-in-cpp.md), [P38 codegen](originals/pytorch-systems-and-deployment-curriculum/modules/38-native-functions-codegen-and-operator-lifecycle.md), [P59 source build](originals/pytorch-systems-and-deployment-curriculum/modules/59-pytorch-source-tree-and-build.md) | Trace one operator lifecycle and fix one well-reproduced compiler/framework issue | Custom-op contract and minimization gates pass |
| CUDA/CUTLASS/CuTe and low-bit kernels | [I37–40 via index](originals/inference-engineering-curriculum/MODULE_INDEX.md), [kernel project](originals/inference-engineering-curriculum/projects/03-kernel-optimization-suite.md) | Optimize one low-bit linear or attention path across a declared shape family | Correct CUDA/Triton oracle comparisons and actual target GPU |

| Serving algorithms | [I33 speculation](originals/inference-engineering-curriculum/modules/33-speculative-decoding.md), [I34 scheduling](originals/inference-engineering-curriculum/modules/34-continuous-batching-chunked-prefill-and-prefix-cache.md), [engine project](originals/inference-engineering-curriculum/projects/04-mini-serving-engine.md) | Turn one simulator mechanism into a measured real execution path; prove sampling correctness if required | Cache/scheduler invariants and runtime source fluency |

TensorRT, TensorRT-LLM, AOTInductor, SGLang and alternate delegates were intentionally comparison/survey routes in the core unless already supported. Make one a primary implementation only when a target role or deployment requirement justifies it. Avoid simultaneously learning every runtime.

For a broader map, use the original [inference extensions](originals/inference-engineering-curriculum/EXTENSIONS_AFTER_CORE.md), [edge next eight weeks](originals/edge-inference-roadmap/guides/next-eight-weeks.md) and [PyTorch what-not-to-miss guide](originals/pytorch-systems-and-deployment-curriculum/WHAT_NOT_TO_MISS.md).
