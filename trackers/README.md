# Active trackers

These files are for your new combined plan. The originals remain unchanged inside `originals/`.

- [daily-progress.csv](daily-progress.csv): one row for each of 273 calendar days; fill actual date, minutes, status, evidence, blocker and next action. The 39 rest rows have no required work.
- [opportunities.csv](opportunities.csv): roles to qualify using current official postings.
- [applications.csv](applications.csv): actual application stages and next actions.
- [interviews.csv](interviews.csv): real feedback, your interpretation and repair exercises.
- [contributions.csv](contributions.csv): current reproduction, policy, test and review evidence.
- [conversations.csv](conversations.csv): relevant professional exchanges and commitments.
- [posts.csv](posts.csv): optional published evidence and its usefulness.
- [offers.csv](offers.csv): only real offers/terms; use the original guide for comparison questions.

The seven career CSVs were copied from the original blank templates; no activities or outcomes were invented. Keep `schedule.csv` as the planned curriculum and record execution here. Suggested statuses for study sessions: `not_started`, `in_progress`, `done`, `blocked`, `deferred`.

If you insert an extra repair day, add a tracker row such as `repair-w08-1` with its real date and actual minutes. The original day numbers remain stable. Summarize milestone results in [PROGRESS.md](../PROGRESS.md). No messages, posts, applications or PRs were sent as part of creating this plan.
