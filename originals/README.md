Use the [combined roadmap](../README.md) for pacing and [coverage map](../COVERAGE.md) for topic placement. The original schedules and full exercises remain intact as optional depth. Original career research, model support and API links are dated snapshots, not current guarantees.

The [manifest](../ORIGINALS_MANIFEST.json) maps each old path to its archived path and checksum. To undo the organization, move the four named directories one level up **only after confirming no same-named destination exists**. That move would require updating links in the combined roadmap; the new plan does not depend on modifying the archived files.
