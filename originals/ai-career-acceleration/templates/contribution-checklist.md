# Contribution preparation checklist

This is an internal checklist. Write actual issue/PR communication yourself according to the target project's current policy, especially llama.cpp's inspected prohibition on AI-written GitHub posts.

- [ ] Read current contribution instructions, applicable AGENTS files and AI policy.
- [ ] Confirm issue state and inspect related/duplicate PRs.
- [ ] Check hardware and test feasibility.
- [ ] Establish expected versus observed behavior with public inputs.
- [ ] Save minimal reproduction, versions and complete error.
- [ ] Agree feature scope if required.
- [ ] Write an independent failing regression check.
- [ ] Make a focused change that fixes the stated behavior.
- [ ] Run relevant tests and record exact coverage/limitations.
- [ ] Inspect every changed line and explain ownership/numeric effects.
- [ ] Follow CLA/DCO/sign-off and disclosure rules.
- [ ] State public status accurately: local, submitted, under review, merged or closed.
- [ ] Respond to feedback without unrelated scope expansion.
